# Инструкция по работе с Cursor на двух компьютерах с сохранением истории чата

## Проблема

История чата в Cursor хранится **локально** на каждом компьютере и **не синхронизируется автоматически** между устройствами. При входе на другом компьютере может произойти конфликт синхронизации, который приведет к потере истории чата.

## Решение: Резервное копирование истории чата

### Где хранится история чата

История чата хранится в базе данных SQLite по пути:
```
C:\Users\[ваше_имя]\AppData\Roaming\Cursor\User\globalStorage\state.vscdb
```

Также есть резервная копия:
```
C:\Users\[ваше_имя]\AppData\Roaming\Cursor\User\globalStorage\state.vscdb.backup
```

### Автоматическое резервное копирование

Используйте скрипт `backup_cursor_chat_history.ps1` для создания резервных копий:

1. **Запустите скрипт перед началом работы:**
   ```powershell
   .\backup_cursor_chat_history.ps1
   ```

2. **Резервные копии сохраняются в:**
   ```
   C:\Users\[ваше_имя]\Documents\CursorChatBackups\
   ```

3. **Каждая резервная копия содержит:**
   - `state.vscdb` - основная база данных с историей чата
   - `state.vscdb.backup` - резервная копия базы данных

### Восстановление истории чата

Если история чата была потеряна, используйте скрипт `restore_cursor_chat_history.ps1`:

1. **Закройте Cursor** перед восстановлением

2. **Запустите скрипт:**
   ```powershell
   .\restore_cursor_chat_history.ps1
   ```

3. **Выберите резервную копию** из списка

4. **Перезапустите Cursor** после восстановления

### Рекомендуемый workflow для работы на двух компьютерах

#### Домашний компьютер (перед завершением работы):

1. Создайте резервную копию:
   ```powershell
   .\backup_cursor_chat_history.ps1
   ```

2. Скопируйте последнюю резервную копию на рабочий компьютер (через облако, USB, сеть)

#### Рабочий компьютер (перед началом работы):

1. Если есть резервная копия с домашнего компьютера:
   - Закройте Cursor
   - Восстановите историю: `.\restore_cursor_chat_history.ps1`
   - Откройте Cursor

2. Перед завершением работы создайте резервную копию:
   ```powershell
   .\backup_cursor_chat_history.ps1
   ```

#### Домашний компьютер (после работы на рабочем):

1. Скопируйте резервную копию с рабочего компьютера
2. Восстановите историю: `.\restore_cursor_chat_history.ps1`
3. Продолжайте работу

### Автоматизация (опционально)

Можно настроить автоматическое резервное копирование через Планировщик задач Windows:

1. Откройте Планировщик задач
2. Создайте новую задачу
3. Установите триггер (например, каждый час или при входе в систему)
4. Действие: запуск PowerShell скрипта `backup_cursor_chat_history.ps1`

### Альтернативное решение: Синхронизация через облако

Можно настроить синхронизацию папки `CursorChatBackups` через:
- OneDrive
- Google Drive
- Dropbox
- Другие облачные сервисы

**Внимание:** Не синхронизируйте напрямую папку `AppData\Roaming\Cursor`, это может вызвать конфликты!

### Экспорт важных чатов

Для сохранения критически важных бесед:
1. Откройте чат в Cursor
2. Используйте функцию экспорта (если доступна)
3. Или скопируйте текст беседы в отдельный файл

## Важные замечания

⚠️ **Всегда закрывайте Cursor перед восстановлением истории!**

⚠️ **Регулярно создавайте резервные копии** - особенно перед переключением между компьютерами

⚠️ **Не синхронизируйте напрямую папку AppData\Roaming\Cursor** - это может привести к потере данных

## Восстановление потерянной истории

Если история была потеряна:

1. Проверьте резервные копии в `Documents\CursorChatBackups\`
2. Проверьте файл `state.vscdb.backup` в папке Cursor
3. Попробуйте восстановить из самой свежей резервной копии

Если резервных копий нет, история, к сожалению, не может быть восстановлена.
