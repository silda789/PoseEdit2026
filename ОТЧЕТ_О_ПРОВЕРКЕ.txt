⚠️ ВОЗМОЖНАЯ ПРОБЛЕМА: ОБНОВЛЕНИЕ DLL
================================================================================
Статус: ТРЕБУЕТСЯ ПРОВЕРКА

Проблема: "На выходном dll старая форма, а не текущая по проекту"

ВОЗМОЖНЫЕ ПРИЧИНЫ:
1. AutoCAD загрузил старую версию DLL и не перезагружает её
2. Visual Studio не пересобрал проект полностью
3. Кэш Visual Studio содержит старые файлы

РЕШЕНИЕ:
См. файл "ИНСТРУКЦИЯ_ПО_СБОРКЕ.txt"

КРАТКАЯ ИНСТРУКЦИЯ:
1. Visual Studio: Build → Clean Solution
2. Visual Studio: Build → Rebuild Solution
3. AutoCAD: NETUNLOAD → выберите PoseEdit2026 → Unload
4. Закройте AutoCAD полностью
5. Откройте AutoCAD заново
6. AutoCAD: NETLOAD → выберите новую DLL → Open
