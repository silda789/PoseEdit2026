## 📋 Рекомендуемый workflow

### Первая настройка на рабочем компьютере

1. **Клонируйте репозиторий:**
   ```bash
   git clone <URL_вашего_репозитория> PoseEdit2026
   cd PoseEdit2026
   ```

2. **Откройте проект в Visual Studio:**
   - Откройте `PoseEdit2026.sln`
   - Восстановите NuGet пакеты (Visual Studio сделает это автоматически)

3. **Настройте пути к ресурсам (если нужно):**
   - Папка `Resources/` уже в проекте и будет синхронизироваться через Git
   - Папка `Temp/` (если используется) должна быть создана локально на каждом компьютере
   - Папка `Standard/` (для файлов настроек) также создается локально

### Ежедневная работа

#### Перед началом работы (на любом компьютере):

```bash
git pull origin main
```

Или в Visual Studio: **View → Git Changes → Pull**

#### После завершения работы:

1. **Проверьте изменения:**
   ```bash
   git status
   ```

2. **Добавьте изменения:**
   ```bash
   git add .
   ```
   Или выберите конкретные файлы через Visual Studio Git Changes

3. **Создайте коммит:**
   ```bash
   git commit -m "Описание изменений"
   ```

4. **Отправьте на GitHub:**
   ```bash
   git push origin main
   ```

### ⚠️ Важные моменты

1. **Не коммитьте:**
   - Файлы в папках `bin/` и `obj/` (уже в `.gitignore`)
   - Пользовательские настройки Visual Studio (`.vs/`, `.user` файлы)
   - Временные файлы из папки `Temp/` (если они специфичны для компьютера)

2. **Всегда коммитьте:**
   - Исходный код (`.cs`, `.xaml` файлы)
   - Файлы проекта (`.csproj`, `.sln`)
   - Ресурсы (`Resources/` папка)
   - Настройки проекта (если они общие)

3. **Перед push всегда делайте pull:**
   - Это предотвратит конфликты, если вы работали на другом компьютере

### 🔧 Решение конфликтов

Если при `git pull` возникли конфликты:

1. **В Visual Studio:**
   - Откройте **View → Git Changes**
   - Разрешите конфликты вручную
   - Сохраните и закоммитьте

2. **В командной строке:**
   ```bash
   # Git покажет файлы с конфликтами
   # Откройте их в редакторе и разрешите конфликты
   git add .
   git commit -m "Resolve merge conflicts"
   git push
   ```

### 📁 Структура папок

```
PoseEdit2026/
├── Resources/          # ✅ В Git (изображения, DWG файлы)
├── bin/                # ❌ НЕ в Git (игнорируется)
├── obj/                # ❌ НЕ в Git (игнорируется)
├── Temp/               # ⚠️ Локально (для тестирования, не обязательно в Git)
└── Standard/           # ⚠️ Локально (настройки, можно добавить в Git если нужны)
```

### 💡 Советы

1. **Используйте осмысленные сообщения коммитов:**
   - ❌ Плохо: "fix", "update", "changes"
   - ✅ Хорошо: "Fix hardcoded path in QuantityTableGenerator", "Add Settings tab to PoseEditWindow"

2. **Делайте коммиты часто:**
   - После завершения логической части работы
   - Перед переходом на другой компьютер

3. **Проверяйте проект после pull:**
   - Убедитесь, что проект компилируется
   - Проверьте, что все ресурсы на месте
