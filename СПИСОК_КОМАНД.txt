1. EEN
================================================================================
ОПИСАНИЕ: Главная команда редактирования поз арматуры
ЧТО ДЕЛАЕТ:
  - Открывает окно WPF (PoseEditWindow) для редактирования атрибутов блока RL-POS
  - Позволяет выбрать существующий блок RL-POS или RL-POS2 для редактирования
  - Или создать новый блок (нажать Enter при выборе)
  - После редактирования можно обновить блок (Update Pose) или отменить (Discard)
  - Для нового блока после сохранения предлагается повернуть его

ИСПОЛЬЗОВАНИЕ:
  - Введите "EEN" в командной строке AutoCAD
  - Выберите блок RL-POS/RL-POS2 или нажмите Enter для создания нового
  - В открывшемся окне отредактируйте атрибуты (POZ, TB, TIP, A, B, C, D, E, F, R, BOY и т.д.)
  - Нажмите "Update Pose" для сохранения или "Discard" для отмены

2. POZVER
================================================================================
ОПИСАНИЕ: Автоматическое назначение номеров позиций выбранным блокам RL-POS
ЧТО ДЕЛАЕТ:
  - Находит максимальный существующий номер POZ среди всех RL-POS* в чертеже
  - Фильтрует выбранные блоки: обрабатывает только те, у которых POZ отсутствует или равен 0
  - Сортирует блоки: сначала по диаметру (из TB) по убыванию, затем по BOY по убыванию
  - Назначает последовательные номера начиная с (максимальный POZ + 1)
  - Блоки, у которых уже есть ненулевой POZ, пропускаются (не перезаписываются)

ИСПОЛЬЗОВАНИЕ:
  - Введите "POZVER"
  - Выберите блоки RL-POS* (можно выбрать все или конкретные)
  - Команда автоматически пронумерует только пустые/нулевые позиции

3. POZCLAYER
================================================================================
ОПИСАНИЕ: Перемещение выбранных блоков RL-POS* на слой ren.mtr.tb
ЧТО ДЕЛАЕТ:
  - Создает слой "ren.mtr.tb" если его нет
  - Перемещает все выбранные блоки RL-POS* на этот слой
  - Полезно для организации чертежа и группировки позиций арматуры

ИСПОЛЬЗОВАНИЕ:
  - Введите "POZCLAYER"
  - Выберите блоки RL-POS*, которые нужно переместить на слой
  - Все выбранные блоки будут перемещены на слой ren.mtr.tb

4. ADET
================================================================================
ОПИСАНИЕ: Изменение количества (adet) в атрибуте TB
ЧТО ДЕЛАЕТ:
  - Запрашивает новое количество арматурных стержней
  - Обновляет атрибут TB, сохраняя множитель (adet carpi), диаметр (Ø) и шаг (aralik)
  - Формат TB: "adetCarpi x adet Ø cap / aralik"
  - Пример: если было "2x20Ø10/100", а вы ввели 25, станет "2x25Ø10/100"

ИСПОЛЬЗОВАНИЕ:
  - Введите "ADET"
  - Введите новое количество стержней
  - Выберите блоки RL-POS*, у которых нужно изменить количество

================================================================================
5. ADET2
================================================================================
ОПИСАНИЕ: Изменение множителя (adet carpi) в атрибуте TB
ЧТО ДЕЛАЕТ:
  - Запрашивает новый множитель количества
  - Обновляет множитель в TB, сохраняя остальные части (adet, Ø, aralik)
  - Если множитель <= 1, он удаляется из TB
  - Пример: если было "20Ø10/100", а вы ввели 2, станет "2x20Ø10/100"
  - Если было "2x20Ø10/100", а вы ввели 1, станет "20Ø10/100"

ИСПОЛЬЗОВАНИЕ:
  - Введите "ADET2"
  - Введите новый множитель (например, 2, 3, 4)
  - Выберите блоки RL-POS*, у которых нужно изменить множитель

6. CAP
================================================================================
ОПИСАНИЕ: Изменение диаметра арматуры (cap) в атрибуте TB
ЧТО ДЕЛАЕТ:
  - Запрашивает новый диаметр стержня
  - Обновляет диаметр в TB, сохраняя множитель, количество и шаг
  - Автоматически устанавливает атрибут TIK = "1" (как в оригинальном LISP)
  - Пример: если было "2x20Ø10/100", а вы ввели 12, станет "2x20Ø12/100"

ИСПОЛЬЗОВАНИЕ:
  - Введите "CAP"
  - Введите новый диаметр (например, 10, 12, 16, 20)
  - Выберите блоки RL-POS*, у которых нужно изменить диаметр

7. ARALIK
================================================================================
ОПИСАНИЕ: Изменение шага (spacing) арматуры в атрибуте TB и ARALIK
ЧТО ДЕЛАЕТ:
  - Запрашивает новый шаг размещения стержней
  - Обновляет шаг в TB (часть после "/"), сохраняя остальные части
  - Также обновляет отдельный атрибут ARALIK
  - Пример: если было "2x20Ø10/100", а вы ввели 150, станет "2x20Ø10/150"

ИСПОЛЬЗОВАНИЕ:
  - Введите "ARALIK"
  - Введите новый шаг (например, 100, 150, 200)
  - Выберите блоки RL-POS*, у которых нужно изменить шаг

ИСПОЛЬЗОВАНИЕ:

9. DEGIS
================================================================================
ОПИСАНИЕ: Массовая замена значений атрибутов по имени
ЧТО ДЕЛАЕТ:
  - Запрашивает имя атрибута для замены (POZ, ADET, ADET2, CAP, ARALIK, BOY, TIP, A, B, C, D, E, F, R, GC, NOT, TB)
  - Запрашивает старое значение (которое нужно заменить)
  - Запрашивает новое значение (на которое нужно заменить)
  - Ищет все выбранные блоки RL-POS* с указанным старым значением и заменяет на новое
  - Для TB-полей (ADET, ADET2, CAP, ARALIK) автоматически пересобирает строку TB

ИСПОЛЬЗОВАНИЕ:
  - Введите "DEGIS"
  - Введите имя атрибута (например, "POZ", "CAP", "BOY")
  - Введите старое значение
  - Введите новое значение
  - Выберите блоки RL-POS*, в которых нужно выполнить замену

10. TDDK
================================================================================
ОПИСАНИЕ: Копирование атрибутов с образца на выбранные блоки
ЧТО ДЕЛАЕТ:
  - Запрашивает выбор образцового блока (источник атрибутов)
  - Читает все атрибуты из образца
  - Запрашивает выбор целевых блоков (INSERT любого типа)
  - Копирует значения атрибутов из образца в целевые блоки (только совпадающие теги)
  - Универсальная команда: работает не только с RL-POS, но и с любыми блоками с атрибутами

ИСПОЛЬЗОВАНИЕ:
  - Введите "TDDK"
  - Выберите образцовый блок (источник данных)
  - Выберите целевые блоки (куда копировать)
  - Атрибуты будут скопированы автоматически

11. TDDB
================================================================================
ОПИСАНИЕ: Автоматическое вычисление и заполнение BOY (общей длины) по сумме сегментов
ЧТО ДЕЛАЕТ:
  - Проходит по всем выбранным блокам RL-POS*
  - Пропускает блоки с TIP = "99" (не вычисляются автоматически)
  - Суммирует значения атрибутов A, B, C, D, E, F
  - Записывает результат в атрибут BOY в формате "L=XXX" (где XXX - сумма)
  - Упрощенная версия: не учитывает радиусы и изгибы, только прямую сумму

ИСПОЛЬЗОВАНИЕ:
  - Введите "TDDB"
  - Выберите блоки RL-POS*, для которых нужно вычислить BOY
  - Команда автоматически заполнит BOY суммой A+B+C+D+E+F

12. TDDH
================================================================================
ОПИСАНИЕ: Вывод содержимого файла error.txt в модель AutoCAD в виде текста
ЧТО ДЕЛАЕТ:
  - Ищет файл error.txt в нескольких местах:

  - Создает объекты DBText в модели AutoCAD, размещая их вертикально друг под другом
  - Высота текста рассчитывается автоматически на основе масштаба чертежа

ИСПОЛЬЗОВАНИЕ:
  - Введите "TDDH"
  - Укажите точку в модели, где разместить текст из error.txt
  - Все строки файла будут выведены как текст в чертеж

13. TDD1
================================================================================
ОПИСАНИЕ: Перестановка позиций атрибутов TB, BOY, NOT по схеме 1
ЧТО ДЕЛАЕТ:
  - Выбирает блоки RL-POS или RL-POS2
  - Перемещает атрибуты TB, BOY, NOT в новые позиции относительно точки вставки блока
  - Схема размещения:
    * TB: смещение на 45*масштаб по углу блока, затем на 10*масштаб вверх
    * BOY: ниже TB на 45*масштаб
    * NOT: ниже BOY на 45*масштаб
  - Используется для корректного размещения текстовых атрибутов на чертеже

ИСПОЛЬЗОВАНИЕ:
  - Введите "TDD1"
  - Выберите блоки RL-POS/RL-POS2, у которых нужно переставить атрибуты
  - Атрибуты будут автоматически перемещены по схеме 1

ИСПОЛЬЗОВАНИЕ:

15. TDD3
================================================================================
ОПИСАНИЕ: Перестановка позиций атрибутов TB, BOY, NOT с учетом длины текста (бывш. tdd5)
ЧТО ДЕЛАЕТ:
  - Аналогично TDD1/TDD2, но учитывает реальную длину текста в атрибутах
  - Вычисляет ширину текста TB и BOY на основе:
    * Высоты текста (Height)
    * Масштаба (ScaleFactor)
    * Количества символов в тексте
  - Размещает атрибуты с учетом их фактической ширины, чтобы они не перекрывались
  * TB: стандартное смещение
  * BOY: смещение на ширину TB + отступ
  * NOT: смещение на ширину BOY + отступ

ИСПОЛЬЗОВАНИЕ:
  - Введите "TDD3"
  - Выберите блоки RL-POS/RL-POS2, у которых нужно переставить атрибуты
  - Атрибуты будут автоматически перемещены с учетом их длины

18. 77B
================================================================================
ОПИСАНИЕ: Поиск источников полей ACAD_FIELD и зум к ним
ЧТО ДЕЛАЕТ:

ИСПОЛЬЗОВАНИЕ:
  - Введите "77B"
  - Выберите поле (текст или атрибут с полем)
  - AutoCAD автоматически приблизит к источникам поля
  - Нажмите Enter для выхода из цикла

19. PZREDEF
================================================================================
ОПИСАНИЕ: Переопределение блоков PZ_* по списку типов из файла REN_QT_tip_file.txt
ЧТО ДЕЛАЕТ:

  - Обновляет определение блока в чертеже, не затрагивая существующие вхождения

ИСПОЛЬЗОВАНИЕ:
  - Введите "PZREDEF"
  - Команда автоматически переопределит все блоки PZ_* согласно списку типов
  - Убедитесь, что файл REN_QT_tip_file.txt существует в папке Standard

20. DIEZ
================================================================================
ОПИСАНИЕ: Отметка всех блоков RL-POS/RL-POS2, содержащих символ '#' в атрибутах, стрелками
ЧТО ДЕЛАЕТ:
  - Сканирует все блоки RL-POS и RL-POS2 в чертеже
  - Проверяет конкатенацию атрибутов: POZ + TB + A + B + C + D + E + F + R
  - Ищет блоки, в которых эта строка содержит символ '#'
  - Запрашивает целевую точку для стрелок
  - Рисует полилинии-стрелки от каждого найденного блока к целевой точке
  - Стрелки размещаются на слое "ren.arrow"
  - Масштаб стрелок: HK = 1000 * DIMSCALE

ИСПОЛЬЗОВАНИЕ:
  - Введите "DIEZ"
  - Укажите целевую точку для стрелок
  - Все блоки с '#' в атрибутах будут отмечены стрелками

21. TDDU
================================================================================
ОПИСАНИЕ: Применение данных опорного блока к другим блокам с тем же POZ
ЧТО ДЕЛАЕТ:
  - Запрашивает выбор образцового блока RL-POS (или Enter для ручного ввода)
  - Если выбран блок: читает POZ, CAP (из TB), BOY, TIP, A, B, C, D, E, F, R
  - Если Enter: запрашивает все эти значения вручную
  - Запрашивает выбор целевых блоков RL-POS
  - Для каждого целевого блока проверяет, совпадает ли POZ с образцовым
  - Если совпадает: обновляет TB (с новым диаметром), BOY, TIP, A..F, R
  - Сохраняет множитель и шаг из исходного TB целевого блока

ИСПОЛЬЗОВАНИЕ:
  - Введите "TDDU"
  - Выберите образцовый блок RL-POS (или нажмите Enter для ручного ввода)
  - Если ручной ввод: введите все значения (POZ, CAP, BOY, TIP, A, B, C, D, E, F, R)
  - Выберите целевые блоки RL-POS
  - Команда обновит только те блоки, у которых POZ совпадает с образцовым

23. PPP2
================================================================================
ОПИСАНИЕ: Поиск блоков с указанным POZ, зум и интерактивный просмотр/удаление
ЧТО ДЕЛАЕТ:
  - Запрашивает номер позиции (POZ)
  - Сканирует все блоки RL-POS и RL-POS2 в чертеже
  - Находит все блоки с указанным POZ
  - Для каждого найденного блока:
    * Выполняет ZOOM к блоку
    * Показывает информацию: "No X/Total - delete this? [Y/N/Exit]"
    * Если Y: удаляет блок
    * Если N: переходит к следующему
    * Если Exit/E: прерывает цикл
  - Позволяет просмотреть и при необходимости удалить все вхождения позиции

ИСПОЛЬЗОВАНИЕ:
  - Введите "PPP2"
  - Введите номер позиции (например, "5", "10")
  - Для каждого найденного блока:
    * AutoCAD приблизит к блоку
    * Введите Y для удаления, N для пропуска, Exit для выхода

24. POZSIL
================================================================================
ОПИСАНИЕ: Очистка позиции (POZ) у выбранных блоков RL-POS* (устанавливает 0)
ЧТО ДЕЛАЕТ:
  - Запрашивает выбор блоков RL-POS*
  - Устанавливает атрибут POZ = "0" для всех выбранных блоков
  - Полезно для сброса нумерации перед повторным назначением позиций

ИСПОЛЬЗОВАНИЕ:
  - Введите "POZSIL"
  - Выберите блоки RL-POS*, у которых нужно очистить POZ
  - Все выбранные блоки получат POZ = "0"
