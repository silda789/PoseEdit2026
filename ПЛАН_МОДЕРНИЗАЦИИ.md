## ПРИМЕЧАНИЯ

1. **#nullable disable**: В проекте используется `#nullable disable` для упрощения работы с AutoCAD API. Это нормально, но можно постепенно переходить на nullable reference types.

2. **WPF и Primary Constructors**: WPF окна не поддерживают primary constructors из-за требования `InitializeComponent()`.

3. **Collection Expressions**: Новый синтаксис C# 12 для массивов и списков - основная фича для модернизации.

4. **Комментарии**: Все комментарии должны быть на русском языке, максимально подробными для новичков.

5. **Обратная совместимость**: Все изменения должны сохранять обратную совместимость с существующим кодом.
