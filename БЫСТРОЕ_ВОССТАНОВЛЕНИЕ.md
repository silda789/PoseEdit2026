# Быстрое восстановление истории чата

## Шаг 1: Закройте Cursor
**Важно!** Cursor должен быть полностью закрыт перед восстановлением.

## Шаг 2: Запустите скрипт восстановления

Откройте PowerShell в папке проекта и выполните:

```powershell
.\restore_cursor_chat_history.ps1
```

Или если скрипт не запускается, выполните вручную:

### Вариант A: Восстановление из встроенной резервной копии

1. Откройте Проводник
2. Перейдите в: `C:\Users\durum\AppData\Roaming\Cursor\User\globalStorage\`
3. Проверьте размеры файлов:
   - `state.vscdb` - основной файл
   - `state.vscdb.backup` - резервная копия

4. Если `state.vscdb.backup` больше по размеру или новее:
   - Закройте Cursor
   - Скопируйте `state.vscdb.backup` 
   - Переименуйте `state.vscdb` в `state.vscdb.old`
   - Переименуйте `state.vscdb.backup` в `state.vscdb`
   - Откройте Cursor

### Вариант B: Ручное восстановление через PowerShell

Выполните в PowerShell (Cursor должен быть закрыт):

```powershell
$cursorPath = "$env:APPDATA\Cursor\User\globalStorage"
$backup = Join-Path $cursorPath "state.vscdb.backup"
$main = Join-Path $cursorPath "state.vscdb"

# Проверяем размеры
if (Test-Path $backup) {
    $backupSize = (Get-Item $backup).Length
    $mainSize = (Get-Item $main).Length
    
    Write-Host "Резервная копия: $([math]::Round($backupSize/1KB, 2)) KB"
    Write-Host "Основной файл: $([math]::Round($mainSize/1KB, 2)) KB"
    
    if ($backupSize -gt $mainSize) {
        # Создаем резервную копию текущего файла
        Copy-Item $main "$main.old_$(Get-Date -Format 'yyyyMMdd_HHmmss')"
        
        # Восстанавливаем из backup
        Copy-Item $backup $main -Force
        
        Write-Host "✓ Восстановлено! Откройте Cursor."
    } else {
        Write-Host "Резервная копия не больше основного файла."
    }
}
```

## Шаг 3: Откройте Cursor

После восстановления откройте Cursor и проверьте историю чата.

## Если не помогло

Проверьте папку резервных копий (если вы их создавали):
```
C:\Users\durum\Documents\CursorChatBackups\
```

Если там есть резервные копии, используйте скрипт `restore_cursor_chat_history.ps1` для их восстановления.
