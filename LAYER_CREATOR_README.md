# Инструкция по использованию команды создания стандартных слоев

## Описание

Создан класс `LayerCreator` и WPF форма `LayerSettingsWindow` для создания стандартных слоев в AutoCAD на основе документа LAYERS-Model.pdf.

**ВАЖНО:** Все параметры слоев (цвет, тип линии, вес линии) уже заданы в стандарте и не требуют настройки. Пользователю нужно только указать префикс и выбрать, какие слои создавать.

## Команды

- **CREATELAYERS** или **CL** - открывает окно для создания стандартных слоев

## Использование

1. В AutoCAD введите команду `CREATELAYERS` или `CL`
2. Откроется окно `LayerSettingsWindow` со списком стандартных слоев
3. Заполните форму:
   - **Prefix** - префикс для всех слоев (например: "std", "ren", "model", "arch")
     - Если префикс = "std", слой "axis" будет создан как "std.axis"
     - Если префикс пустой, слои создаются без префикса
   - **Standard Layers** - список из 41 стандартного слоя с предустановленными параметрами
     - Отметьте чекбоксами слои, которые нужно создать
     - Используйте "Select All" / "Deselect All" для массового выбора
   - **Skip existing layers** - пропускать существующие слои (по умолчанию включено)
4. Нажмите "Create Layers" для создания выбранных слоев

## Примеры

### Пример 1: Создание всех слоев с префиксом "std"

1. Введите команду `CREATELAYERS`
2. В поле "Prefix" введите: `std`
3. Нажмите "Select All" для выбора всех слоев
4. Нажмите "Create Layers"

Результат: создадутся слои `std.annotation`, `std.axis`, `std.wall`, `std.column` и т.д. (всего 41 слой)

### Пример 2: Создание только некоторых слоев с префиксом "ren"

1. Введите команду `CREATELAYERS`
2. В поле "Prefix" введите: `ren`
3. Отметьте только нужные слои (например: `axis`, `wall`, `column`, `beam`)
4. Нажмите "Create Layers"

Результат: создадутся только выбранные слои: `ren.axis`, `ren.wall`, `ren.column`, `ren.beam`

### Пример 3: Создание слоев без префикса

1. Введите команду `CREATELAYERS`
2. Оставьте поле "Prefix" пустым
3. Выберите нужные слои
4. Нажмите "Create Layers"

Результат: создадутся слои без префикса: `axis`, `wall`, `column` и т.д.

## Стандартные слои

Всего доступно **41 стандартный слой** с предустановленными параметрами из документа LAYERS-Model.pdf:

### Основные категории слоев:

1. **Оси и размеры:**
   - `axis` - координационные оси (цвет 8, Center, 0.2mm)
   - `axis.circle` - обозначения осей (цвет 8, Center, 0.2mm)
   - `axis.dimension` - осевые размеры (цвет 12, Center, 0.2mm)
   - `axis.text` - текст названия осей (цвет 3, Continuous, 0.2mm)
   - `dimension` - размеры (цвет 1, Continuous, 0.2mm)

2. **Конструкции:**
   - `wall` - стены (цвет 150, Continuous, 0.6mm)
   - `column` - колонны (цвет 4, Continuous, 0.6mm)
   - `beam` - балки (цвет 134, Continuous, 0.2mm)
   - `beam.bot` - скрытые линии балок (цвет 135, Dashed, 0.2mm)
   - `foundation` - фундаменты (цвет 124, Continuous, 0.6mm)
   - `section` - линии в сечении (цвет 4, Continuous, 0.6mm)

3. **Арматура:**
   - `reinforcement` - арматура (цвет 7, Continuous, 0.6mm)

4. **Текст и аннотации:**
   - `text` - текст на чертеже (цвет 3, Continuous, 0.2mm)
   - `annotation` - текст описаний (цвет 2, Continuous, 0.2mm)
   - `table` - таблицы и спецификации (цвет 12, Continuous, 0.2mm)
   - `title` - основная надпись (цвет 5, Continuous, 0.6mm)
   - `title.text` - текст в штампе (цвет 1, Continuous, 0.2mm)

5. **Вспомогательные:**
   - `hatch` - штриховки (цвет 8, Continuous, 0.2mm)
   - `arrow` - стрелки и указатели (цвет 34, Continuous, 0.2mm)
   - `secondary` - вторичные линии (цвет 8, Dashed, 0.2mm)
   - `line.hidden` - скрытые линии (цвет 8, Hidden, 0.2mm)

И другие... (полный список см. в окне программы)

### Параметры слоев

Все параметры слоев (цвет, тип линии, вес) уже заданы в стандарте и **не требуют настройки**. Они автоматически применяются при создании слоев.

### Опции

- **Skip existing layers** - пропускать существующие слои (не обновлять их)
  - Если включено: существующие слои пропускаются
  - Если выключено: свойства существующих слоев обновляются согласно стандарту

## Структура файлов

- `LayerCreator.cs` - класс с командой создания слоев и стандартными слоями
- `LayerSettingsWindow.xaml` - WPF форма для выбора слоев и префикса
- `LayerSettingsWindow.xaml.cs` - код-бихайнд формы
- `LayerSettings` - класс для хранения настроек
- `LayerDefinition` - класс для определения одного слоя с параметрами
- `StandardLayers` - класс со списком стандартных слоев из LAYERS-Model.pdf

## Примечания

- **Префикс обязателен для стандартизации:** рекомендуется всегда использовать префикс (например: "std", "ren", "model")
- Префикс добавляется к каждому имени слоя через точку (например: `std.axis`, `ren.wall`)
- Если префикс не указан, слои создаются без префикса (не рекомендуется)
- Если слой уже существует и опция "Skip existing layers" включена, он будет пропущен
- Если опция "Skip existing layers" выключена, свойства существующего слоя будут обновлены согласно стандарту
- Все параметры слоев (цвет, тип линии, вес) заданы в стандарте LAYERS-Model.pdf и не требуют настройки
- Слой "Defpoints" создается с весом линии "ByLayer" (непечатаемый слой)

## Технические детали

### Класс StandardLayers

Содержит 41 предустановленный слой с параметрами:
- Имя слоя (Name)
- Индекс цвета (ColorIndex) - от 1 до 255
- Тип линии (Linetype) - Continuous, Dashed, Center, Hidden
- Вес линии (LineWeightMM) - в миллиметрах (0.2, 0.3, 0.6) или null для ByLayer
- Описание (Description) - на русском и английском

### Автоматическое преобразование

- Вес линии в миллиметрах автоматически преобразуется в LineWeight AutoCAD
- Типы линий (Center, Dashed, Hidden) должны существовать в чертеже AutoCAD
